# 🛍️ Mohamed Online Store (E-commerce App)

A modern, fully responsive e-commerce web application built using **React**, **TypeScript**, **Vite**, **Swiper.js**, and **DummyJSON API**.

---

## ✨ Features 
- 📱 **Fully Responsive Design:** Optimized seamlessly for mobile, tablet, and desktop viewports.
- 🔄 **Product Sliders (Swiper.js):** Smooth touch-enabled product carousels for categories and featured items.
- 🌐 **DummyJSON Integration:** Dynamic product data fetching with rich attributes and images.
- 🛒 **Shopping Cart & Favorites:** Full state management for adding items to cart, managing quantities, and toggling favorites.
- 🔍 **Live Search Bar:** Real-time product search with instant dropdown suggestions.
- 📤 **Web Share API:** Native product sharing capability with a clipboard fallback.
- 🔔 **Interactive Toasts:** User notifications using `react-hot-toast`.

---

## 🛠️ Technologies Used 
- **React (TSX)**
- **TypeScript**
- **Vite**
- **Swiper.js**
- **DummyJSON API**
- **React Router DOM**
- **React Icons**
- **React Hot Toast**
- **CSS3 (Flexbox & Media Queries)**
